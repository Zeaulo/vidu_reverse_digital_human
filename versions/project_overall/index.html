Vidu 直播桥 · 开发手册 v0.14.1

以 FastAPI 管理会话，通过 douyinLive 匿名采集抖音事件，队列调度向 Vidu 业务 WebSocket 发送指令，官方 SDK 在有头 Chrome 内处理 RTC 音视频，再经本机 WebRTC 播放在 Studio 和 OBS。

已验证：真实评论自动发送 21 条、接受 21 条，控制台视频帧持续增长，音频能量非零。未验证：真实礼物、真实超时重建、新验证码登录重测。OBS 浏览器源已支持本机令牌播放并通过合成媒体测试，真实 Vidu 和 OBS 联调仍待验证；RTMP 推流未集成。

项目架构拆解

代码逻辑层

  1. 根目录 start.cmd 切换到项目目录并设置终端 UTF-8，调用 test/start_studio.ps1；脚本检查 .venv、采集器及配置，通过 test/release_port.ps1 强制结束监听 8795 的进程并等待端口释放，再使用虚拟环境 Python 启动 Uvicorn；1088 采集器沿用现有监听。
  2. web/assets/app.js 在页面末尾的直播间事件区显示启停、状态及统计；评论置顶，进入和点赞各自显示计数与最近记录，礼物及关注独立列出。各区按接收时间从新到旧显示本地时间，可导出完整 UTF-8 JSON。事件统计区分收到、入队、发送和回执，未知房间状态明确提示采集已停止。
  3. web/assets/vidu.js 根据浏览器、登录、通话状态解锁四步操作，完成时自动折叠；账号、通话和指令操作反馈位于对应按钮附近；media.js 单独显示声音与画面重连反馈。
  4. app/main.py 注册静态网页、房间启停、事件查询及入口；退出时逐个清理采集、通话、浏览器。
  5. app/api/vidu.py 用 HttpOnly studio_session 映射独立 API、CallRecovery、LiveBridge 和操作锁。Host、Origin、X-Studio-Request 校验限制本机调用。
  6. ViduBrowserApi 按需启动可见 Chrome。浏览器 fetch 执行短信、登录和用户接口；角色 live-pro 页负责 claim 和 SDK 初始化。登录成功后 Vidu Cookie 以 Windows 当前用户 DPAPI 加密保存最多 24 小时；账号恢复时在隔离浏览器上下文中调用用户接口校验，支持删除保存账号。控制台浏览器单独保存手机号、角色 ID 和已接受消息候选。
  7. vidu_runtime.js 接管固定业务 WebSocket 的发送序号，共享 seq_id，发送 type 12 文本并等待匹配的 type 14；type 15 等待三秒识别审核提示，未识别时只报告对应消息失败，不把单条错误升级为挂断；实际连接关闭和挂断仍单独处理。不会操作官网输入框。
  8. LiveBridge 启动采集与消费两个任务；DouyinAdapter 使用 ws://127.0.0.1:1088/ws/房间号。ROOM_ONLINE 才显示已连接；未知或不存在状态停止读取。
  9. media_relay.js 收集官方媒体轨道，以本机 RTCPeerConnection 回答 Studio SDP offer；视频发送端按会话目标设置 100%、80% 或 50% 缩放，请求分辨率优先与 8 Mbps 编码上限，并暴露脱敏源轨道、控制台和 OBS 发送统计。web/assets/media.js 显示源轨道、转发与接收端画质指标，支持自动播放、声音开关与重协商。

功能需求层

消息可通过回车发送，成功接受的消息提供本地高频历史候选；通话授权按用户要求固定勾选。直播记录：采集事件按接收时间显示，列表每类最多 80 条；完整记录保存在临时归档，可通过本机会话导出，连接新房间会清空旧归档。账号：步骤 1 显式启动有头浏览器，步骤 2 使用手机号与验证码登录；本地不设短信冷却，仍显示上游限流。登录协议默认勾选，用户可以取消；清除登录态销毁资源。角色：步骤 3 输入角色 ID 后创建通话，已连接后折叠，可展开并断开以切换角色；步骤 4 在媒体连接后解锁自定义发送。通话授权依据用户要求默认选中。采集：输入数字房间号即可启动，停止采集不停止通话。事件：评论默认入队；暖场启用后进入、点赞和礼物进入队列并生成包含用户名的欢迎或感谢指令；关闭时删除未发送的暖场任务；每条展示 observed、queued、sending、accepted、expired、dropped、unknown 状态。

调度：队列容量 30；消息存活 30 秒；最小间隔 3.5 秒；礼物优先；媒体未连接时暂停；回执不明不自动重发；可关联到当前唯一待处理消息的审核拒绝标记为审核未通过，后续事件继续调度。通话恢复：每两秒检测，audit_rejected 时检查官网信令状态、视频轨道和解码帧增长，不主动跳页，检查期间暂停发送；即使业务信令关闭，只要官网视频帧持续更新仍保留画面；等待十秒内可能延迟出现的明确结束提示；仍无法确认画面持续更新时提示处理。明确超时或 duration_limit 后 5/10/20 秒退避，每次手动开始最多自动重建三次，登录失效、额度结束、手动停止和未知错误不继续创建。

媒体：转发比例默认 100%，可切换至 80% 或 50%，会话内同时应用于控制台和 OBS，重连后沿用；显示目标尺寸、实际转发尺寸、参数回读及 CPU／带宽限制原因。默认静音预览，点击开启声音；播放时周期缓存最近一帧，恢复期间显示静态画面与状态，收到新帧后切回视频，手动停止时清除缓存；同一会话支持控制台和一个 OBS 浏览器源并行接收；相同类型的后续接收端会替换该类型旧连接。OBS 本机链接在 URL 片段携带随机播放令牌，退出登录、撤销或重启服务后失效，不是 RTMP/FLV 地址。

内容审核结束恢复链路

ViduBrowserApi.runtime_status 同时匹配“通话已结束”“当前内容不符合规范”“直播已结束”，该页面证据优先于已有信令原因。CallRecovery 观察视频轨道与累计帧：持续增帧时保留通话；停止后在启用自动恢复的情况下等待五秒，停止旧通话、复核登录并最多创建一次新通话。出现提示时 LiveBridge.pause_for_policy 丢弃队列、保留事件归档，暂停期间新事件只记录；媒体重新连通后才恢复新事件调度。再次出现同一结束提示、登录或创建失败时停止自动恢复；手动开始新通话重置本轮预算。恢复可能消耗额度，模拟测试不代表真实官网联调成功。

数据流动层

  1. 访客采集器 → protobuf JSON → 系统状态分流 → LiveEvent → 事件统计和历史。
  2. EventFilter → 内容长度、开关、短期去重 → 优先队列 → CallRecovery.send → 浏览器 type 12 → accepted 回执更新原记录。
  3. Studio 角色 ID → claim → live.id、rtc.user_id、rtc.token 留在服务上下文 → 官方 SDK 加入 RTC。
  4. 官方远端音视频轨道 → 本机 SDP 协商 → Studio video.srcObject → 持续解码和音频播放。
  5. 官网明确超时 → 挂断旧通话 → 登录复核 → 新 claim → 新 live_id → 播放器重新协商。没有真实超时验证记录时不宣称此链路实测通过。

核心目录树与关键文件

app/main.py
FastAPI 生产入口。/api/session/room 启动会话专属采集；/api/events 返回历史与计数；/api/danmaku 需要 Studio Cookie 和自定义头，不兼容未经认证的旧 reader.py 直接推送。
app/api/obs.py、app/storage/obs_access.py
OBS 只通过本机同源接口和随机令牌读取当前会话状态并协商独立媒体；令牌存于内存，复制时复用，轮换或撤销关闭旧接收端；不返回账号、Cookie 和媒体令牌。
web/obs.html、web/assets/obs_player.js、web/assets/obs.css
OBS 浏览器源播放页面通过 URL 片段获取凭证，使用请求头协商音视频，通话变化后重连并在等待期间保留上一帧；声音被浏览器阻止时提示通过 OBS 交互启用。
app/api/vidu.py
status、browser/start、sms、login、accounts、accounts/restore、accounts/forget、claim、command、stop、logout、media/answer、media/quality、media/quality/settings。browser/start 显式启动有头浏览器，status 返回窗口就绪状态。首次 status 创建隔离会话，最多 16 个。错误校验不回显验证码。
app/adapters/vidu_browser.py
有头 Chrome 生命周期、上游 fetch、媒体页导航、通话停止和 SDP 回答。关闭 Chrome 会导致媒体不可用。
app/adapters/vidu_runtime.js
type 1/2 初始化、type 11 媒体状态采样、type 12/14 指令和回执、type 5/6/10 结束信令与业务 WebSocket 是否打开。15 秒没有回执时报告未知且不重发。
app/adapters/moderation_dialog.js
仅在标题、内容政策提示与唯一可见确认按钮都匹配时关闭审核弹窗；唯一待处理消息标记审核未通过，不重发、不主动挂断。真实官网弹窗形态和信令时序尚需实际验证；未匹配弹窗的指令错误也不会主动挂断。
app/adapters/media_relay.js
轨道去重、控制台与 OBS 两个独立 RTCPeerConnection 接收端、十秒 ICE 收集超时；视频发送端根据会话选择动态设置 100%、80%、50% 缩放及分辨率优先，读取参数与限制原因；设置失败时保持可用并提示；停止中继不会停止官方原始轨道。
web/assets/history.js
本浏览器 localStorage 保存最近最多 20 个成功登录手机号、成功连接角色 ID 和成功连接的直播间 ID，以及最多 50 条收到接受回执的消息，支持频率排序与单独清除；不保存验证码、Cookie 或令牌。
app/adapters/douyin.py
识别 WebcastChatMessage、WebcastGiftMessage、WebcastLikeMessage、WebcastMemberMessage。支持 camelCase 与 snake_case 礼物字段，连击只取最终包，其余业务类型忽略。
app/services/live_bridge.py
采集器任务、30 条队列、每种类型各 80 条页面历史、临时完整归档、计数器、过期清理、优先发送；切房取消旧任务，退出登录清空队列。
app/storage/saved_accounts.py
以 Windows DPAPI 加密当前系统用户的 Vidu Cookie 与手机号，24 小时后禁止恢复；服务运行时每分钟清理过期记录，可单独删除账号。Cookie 不返回给前端，恢复时必须验证上游用户接口。
app/utils/diagnostics.py
在 logs/call_diagnostics.log 记录不包含消息正文和凭据的发送结果与断线原因类别，采用滚动文件；未知断线不会伪装为已知根因。
app/storage/event_archive.py
每个 Studio 会话独立的 SQLite 临时归档；记录完整事件和调度状态，重新连接清空，退出登录或服务停止时关闭，导出接口仅读取当前会话。
app/services/event_filter.py、app/domain/events.py
事件开关、120 字长度、敏感词、八秒内容去重；事件模型生成感谢礼物、欢迎、点赞和评论提示。
app/services/call_recovery.py
独立通话锁和 generation 防止停止期间复活；audit_rejected 分支检查视频帧增长并等待明确结束提示；内容审核明确结束后暂停队列，确认媒体停止时最多恢复一次；媒体从开始等待或断流时起连续 90 秒未就绪才停止，不将通话已持续时间算作断流时长，不盲目创建付费会话。
app/adapters/vidu_api.py、vidu_ws.py、vidu.py
早期直接 HTTP/WS 和 DOM 适配实验。ViduApi 仍提供短信和登录公用方法；Studio 默认发送路径使用 ViduBrowserApi 与运行时信令。
app/config/settings.py、config/config.example.yaml
端口和采集器地址、过滤规则、队列容量与发送间隔。config/config.yaml 为本地覆盖，不提交凭据。
web/index.html、web/assets/app.js、vidu.js、media.js、style.css
深色玻璃控制台、账号四步流程、音视频播放器、直播间事件分区及完整记录下载。首次会话初始化共用 Promise；外部事件仅 textContent 渲染。
LICENSE、.gitignore、README.md
MIT 许可仅覆盖本项目自有代码；公开仓库忽略登录数据、日志、测试音视频及第三方采集器。README 记录独立安装依赖、第三方服务边界和启动方法。
start.cmd、.venv/、requirements.txt
Windows 双击入口、项目独立 Python 环境和依赖清单。虚拟环境不提交 Git；迁移机器时须重建并安装依赖。
test/probe_vidu_audio.py、test/vidu_audio_probe_init.js、test/analyze_audio_probe.py
独立测试会话中将用户音频短片段注入 RTC 麦克风，采样上行与远端接收统计、脱敏 WebSocket 字段，并本地分析远端录音；默认不会连接 Vidu，实际执行需显式 --execute、--audio 和 --avatar，生成内容保存在 test/artifacts，不记录凭据。WebSocket 直接音频输入和歌曲跟唱均未证实。
test/check_media_freeze.py、test/check_media_quality.py、test/check_ui_feedback.py、test/check_room_status.py
check_relay_resolution.py 使用 768×1364 合成视频采样三档编码尺寸；check_obs_media.py 用合成音视频验证 OBS 与控制台并行接收及三档参数应用；check_obs_player.py 验证播放页重连和令牌失效；test_obs_api.py 验证令牌隔离与轮换；check_media_freeze.py 验证视频静态帧、中断和恢复；check_media_quality.py 通过合成轨道检查本机 WebRTC 媒体协商和源尺寸；check_ui_feedback.py 用模拟接口验证历史记录与步骤解锁、自动折叠和断开；check_room_status.py 使用独立本机会话检查指定房间，只输出状态和计数，结束后停止采集并清除测试会话。
test/release_port.ps1、test/test_release_port.ps1、test/port_listener.ps1
启动前按 PID 去重并强制释放 8795；隔离测试使用临时端口启动专用监听器，验证端口占用和空闲两种情况。结束旧 Studio 进程会丢失尚未导出的直播记录。
test/start_studio.ps1、test/guest_probe.py
本机启动和三十秒真实匿名采集验证；采集测试需要显式传入房间 ID。test/tools 存已校验 douyinLive 二进制与访客配置，不提交 Git。
test/test_policy_recovery.py
使用本地 Chrome 和模拟通话验证结束文案的完整匹配、审核信号延迟、视频帧观察、队列清空、一次性恢复、手动停止和登录校验失败；不触发真实审核。
test/test_api.py、test_events.py、test_vidu.py、test_recovery.py、test_bridge.py、test_runtime.cjs
API 校验、过滤、账号隔离、回执匹配、恢复预算、停止取消、真实字段解析、队列优先级、过期及未知回执不重发。
test/integration_server.py、test/probe_browser.py、test/headed_probe.js
临时本机联调工具。一次性随机密钥限定授权会话内存迁移，生产入口不加载这些路由；不把测试登录态写入仓库。
