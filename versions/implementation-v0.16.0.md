# v0.16.0 实施方案

1. 使用抖音礼物目录响应的 `is_displayed_on_panel` 字段，将礼物标记为用户面板可见或系统隐藏；当前快照为 418 个可见 ID、788 个隐藏 ID。
2. 目录导入、历史基线和当前房间缓存保存 `is_displayed_on_panel` 与 `visibility_source`，不依据名称、图片或价格猜测可见性。
3. 礼物目录接口默认只显示明确的面板可见 ID，增加 `include_hidden` 查询参数；启用后返回隐藏和状态未知礼物，并分别标识和统计。
4. 控制台增加“显示系统隐藏礼物”复选框，切换后重置分页；礼物绑定搜索沿用同一过滤设置，并在选择项和目录表中显示“系统隐藏”。
5. 礼物接收解析不因目录可见性过滤，手工填写隐藏 ID 仍可绑定；可见性只控制目录展示，避免漏掉实际直播事件。
6. 增加可见性导入、查询默认过滤、隐藏切换、同名不同 ID 和 API 会话隔离测试；更新 v0.16.0 版本日志、使用说明和项目总览。
