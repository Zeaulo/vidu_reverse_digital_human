# v0.15.0 实施方案

本次按已确认的实施范围执行，以 GitHub main 的 v0.14.2（d9b80fc）为基础，先备份本地文件，再合并。

1. 保留上游 OBS 输出、账号加密保存、事件归档、审核恢复及媒体链路。
2. 合并礼物解析、连击结算、目录查询与刷新；目录显示 ID、名称、参考价格和图片。
3. 在「Vidu 账号与接口指令」增加礼物规则：礼物 ID、累计数量门槛、自定义指令、启用、礼物答谢（默认勾选）。支持昵称、礼物名称、数量占位符；同一连击同一规则仅触发一次。
4. 答谢开启时，向 Vidu 发送先感谢指定用户、再执行配置指令的单条文本。指令仍经现有信令接口发送。
5. 暖场拆分为欢迎进入直播间、谢谢点赞、回复弹幕三个独立开关；默认关闭欢迎与点赞、开启回复弹幕。礼物独立调度。
6. 删除或修改规则、关闭互动开关时，取消对应尚未发送的任务；审核恢复、断线期间不重放状态不明的任务。
7. 增加解析、连击、规则、会话隔离、接口和 UI 验证，运行上游回归测试；真实礼物和 Vidu 实测必须与模拟测试分开报告。
8. 版本更新至 v0.15.0，同步维护更新日志与内部项目总览。提交前检查凭据和运行产物不进入 Git。
